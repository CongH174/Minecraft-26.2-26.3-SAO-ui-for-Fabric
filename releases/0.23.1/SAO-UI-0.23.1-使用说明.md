# SAO UI 0.23.1 使用说明

同一个 Fabric JAR 支持 Minecraft 26.2／26.3。替换旧 SAO UI JAR，保留 config/saoui.json。

## 附魔面板勾选框

K → 装备，右侧附魔面板顶部新增“查看可附魔的最高等级”方框。

- 不勾选：显示所选物品实际拥有的附魔、真实等级和物品原文；附魔书显示实际储存的附魔。
- 勾选：显示当前世界允许用于此物品的每一条魔咒及其最高等级，包括适用的数据包魔咒。普通书／附魔书可预览当前世界的魔咒列表。

预览明确标注“未生效”。各条独立列出，不表示互斥魔咒可同时附加；此操作不会修改物品、消耗材料或保存配置。原版默认参考区块仍然移除。

点击方框切换，也可在方框获得焦点后用空格键操作。鼠标悬停可查看解释。切换模式会回到列表顶部；滚轮、折叠和右上 [+] 放大阅读继续可用，阅读视图会显示当前模式。

当前这次菜单会在更换物品、切换页面和调整窗口大小时保留勾选状态。关闭后重新打开菜单，默认回到实际附魔。

## 保留 0.23 功能

AppleSkin 手持食物恢复预览、呼吸动画、主副手优先级和透明度联动保持可用；HUD 设置中的独立预览开关继续使用统一保存／取消。左右布局、两种血条样式和其余菜单功能保留。

安装仍需 Java 25、Fabric Loader 0.19.3+ 和对应游戏版本的 Fabric API。AppleSkin 为可选依赖，不内置在成品中。
