# SAO UI 0.26.0 — 伽马复写

统一JAR适用于Minecraft 26.2 / 26.3。移除旧SAO UI文件，将sao-ui-0.26.0+mc26.2-26.3.jar放入mods；原有配置继续使用。

## 使用

在游戏中按G切换“伽马复写”，动作栏会显示开／关。默认关闭，离开世界时关闭。

按键可在原版“选项 → 控制 → 按键绑定 → SAO UI”中更改，名称为“伽马复写（夜视亮度）”。与K菜单键相互独立，在菜单或输入界面中按此键不会切换。

## 效果

开启后在原版光照渲染阶段将伽马覆盖为16，使暗处达到高亮、类似夜视的效果。不会修改原版亮度设置或写入options.txt，不会给角色添加药水效果，也不会改变方块光照或服务器状态。

关闭后继续使用当前的原版亮度值；开启期间在选项中调整的亮度也会保留。原有SAO设置、菜单动画和其他功能保留。

## 验证范围

仅验证真实暗室中的开／关效果、原生独立按键及改键、亮度恢复、菜单输入隔离、退出世界关闭，以及同一根JAR在26.2和26.3的实际加载。没有重复执行无关模组兼容测试。结果和SHA256见同目录validation.txt。
