# SAO UI 0.21.0 使用说明

本版统一支持 Minecraft 26.2 / 26.3，只需安装一个 JAR。

## 本轮改动

- 装备摘要按类型展示：近战、远程、护甲、工具、盾牌、附魔书。护甲显示护甲值/韧性，盾牌和工具不再显示通用近战 DPS。
- 附魔说明按物品原文、实际魔咒、原版参考分开阅读。点击标题可折叠；原版参考默认折叠。同一选中物品更新耐久等组件时保留滚动位置。
- 魔咒面板右上角 [+] 打开放大阅读视图。字号根据物理窗口计算；Esc 或“返回”关闭阅读视图，仍留在当前物品和菜单。
- HUD 可拖动定位、靠近边缘/中心吸附、方向键微调，并保留精确位置输入和缩放。
- 容器/背包布局可拖动编辑，并调整相对方向、间距和精确偏移。预览为通用容器示意，具体槽位与工作台内容仍使用实际原生界面。

## 入口与保存

1. 设置 → HUD 设置 → 调整 HUD 布局。
2. 设置 → 界面设置 → 方块规则 → 可视化布局。
3. 子编辑器的“应用到草稿”只返回上级，不立刻写入生效配置；最后在主设置页完成保存。方块规则还需在规则编辑页完成一次上级确认。
4. 子编辑器取消/Esc 丢弃该子编辑器的修改；主设置页取消丢弃本次全部草稿。

## 安装

退出需要更新的游戏实例，移除旧版 SAO UI JAR，把 sao-ui-0.21.0+mc26.2-26.3.jar 放入 mods 后重新启动。保留原有 config/saoui.json。

- Java 25；SAO 本身要求 Fabric Loader >= 0.19.3。
- 26.2：对应 Fabric API >= 0.152.1+26.2。
- 26.3：对应 Fabric API >= 0.164.0+26.3。
- 第三方模组可能要求更高的 Loader；沿用已适用的模组组合即可。

## 数据边界

物品 Lore 仍是物品级原文，不自动分配给单条魔咒。名称和实际等级继续来自原生附魔组件；未同步的服务器脚本与公式不会被推测补全。布局预览不打开容器、不修改物品、不发送合成或库存操作。

## 验证

最终交付的同一 SHA256 根 JAR 在 26.2 / 26.3 各自实际加载，运行时来源为 NESTED/saoui。每版通过 59 项 JUnit 测试、12 组功能 GameTest 及成品身份检查。新增验收包括原生左键拖动、非法数值、缩放与尺寸变化、父子草稿、保存/取消/磁盘持久化、附魔折叠、放大阅读与返回，以及原生耐久同步后的阅读位置。
