# SAO UI 0.22.0 使用说明

适用于 Minecraft 26.2 / 26.3 的同一个 Fabric JAR。替换旧版 SAO UI，保留 config/saoui.json；不要同时安装多个 SAO UI 版本。

## 右侧 HUD 与样式

K → 设置 → SAO 设置 → HUD 设置：

- **HUD 放在右侧**：整组生命、饱食度、经验、护甲条镜像到右侧；文字正常阅读。关闭恢复左侧。默认关闭，旧配置保持原布局。
- **血条样式**：下拉菜单提供“SAO 切角”和“纯矩形”，以后可继续增加样式。默认仍为 SAO 切角。
- **可视化 HUD 布局**：右侧模式按右边距定位；拖动、方向键、数值调整与缩放使用同一布局。窗口改变后仍按选定边缘定位。右侧默认高度自动避开原版效果图标；自定义高度后以你的设置为准。

状态颜色与金色吸收层保留。各状态条、原版 HUD 元素仍独立控制，原版快捷栏一直保留。

## 角色状态

K → 角色：显示实时生命与吸收、饱食度、Minecraft 经验等级及升级所需经验、背包已用/空余格数、手持/副手/穿戴装备中最低耐久、当前状态效果及剩余时间、坐标。保留人物预览，底部直接进入物品栏或装备。仅显示客户端实际同步的数据，不推算服务器隐藏属性。

背包统计包含 36 个主背包/快捷栏槽位，不包含护甲、副手或额外合成格；耐久取当前手持、副手及已穿戴装备。状态较多时显示前两项及其余数量。

## 更浅的可视化布局入口

K → 设置 → SAO 设置 → **界面设置顶部** → 方块界面／背包 · 可视化布局，直接调整全局默认位置、间距和左右关系。逐方块及坐标覆盖继续优先；特定规则在原方块设置中编辑，入口已移到表单标题旁。

## 修复与设置说明

“附魔物品原文说明”现在明确显示“开／关”。原问题是点击已改变草稿，但按钮没有状态占位符；现已修复中英文反馈。所有新控制与样式选项都有解释性悬停提示。

所有设置先进入草稿。布局编辑器点“应用”只合并到上层草稿，最后在 SAO 设置点“完成”统一保存；“取消”丢弃此次修改。

## 安装条件

Java 25、Fabric Loader 0.19.3+，以及匹配当前 Minecraft 版本的 Fabric API。26.2 至少 0.152.1+26.2，26.3 至少 0.164.0+26.3。AppleSkin、IPN 仍为可选依赖，不打包在 SAO UI 内。
